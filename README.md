# 🧟 Zombie Shooter Game

A first-person zombie shooting game developed in Unity and C#. The player fights through a temple environment, eliminates waves of zombies, collects objectives, and faces a final boss encounter.

## 🎮 Game Features

* First-person shooter gameplay
* Random zombie spawning and enemy pursuit
* Raycast-based shooting system
* Zombie death effects using Unity Particle System
* Collectibles and progression-based gameplay
* Animated door and boss reveal sequence
* Multi-hit boss battle
* Boss defeat animation
* Game over and level completion logic
* Restart and return-to-main-menu options

## 🕹️ Gameplay

The player starts inside a temple where zombies are spawned and move toward the player.

The player must:

1. Shoot and eliminate the zombies.
2. Collect the required collectibles.
3. Progress through the level and trigger the animated door sequence.
4. Face the final boss.
5. Shoot the boss five times to defeat it.
6. Restart the game or return to the main menu after completion.

## 🛠️ Technologies Used

* Unity
* C#
* Unity Raycasting
* Unity Particle System
* Unity Animation System
* Unity UI

## 📌 Project Highlights

This project demonstrates practical implementation of FPS mechanics, enemy behavior, raycast-based combat, particle effects, animation, game-state management, and UI navigation in Unity.
